What do the bits mean?

Each pair 00 / 01 / 10 / 11 picks an available, unvisited neighbor at a junction. Options are ordered right, down, left, up. A corridor follows automatically.

A plan can run out of choices, pick an unavailable option, or hit a dead end. After reaching G, unused pairs must be 00 so the same route is not counted repeatedly.

3. Count the work honestly


These counts use different units. Python already checks every encoded plan to build the truth-table oracle. Corridor following is classical work. The oracle is one logical diagonal operation, not a reversible maze-checking gate decomposition. This project demonstrates amplitude amplification, not a laptop speedup over BFS.


BFS is complete on this grid and finds a shortest path. Grover searches only the encoded plans and does not minimize route length. More iterations can reduce success after the optimum.
